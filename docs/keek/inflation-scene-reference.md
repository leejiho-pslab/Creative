## 2. ⭐ 주입 동작의 실제 묘사

### 2-1. 노즐 처리 (8.4~10.1초 구간에서 가장 선명)

프레임을 확대해 확인한 결과:

- **짧은 검정 원통형 노즐**을 **입술 사이에 문다**
- 손은 노즐 아래를 **감싸 쥐는 형태** — 엄지와 검지로 잡고 나머지 손가락은 말아 쥠
- 노즐은 **아래에서 위로**, 즉 칼라 쪽에서 올라온다
- **호스 자체는 거의 안 보인다.** 화면에 드러나는 건 입술에 닿은 노즐 끝뿐
- 입술은 오므린 상태. **볼을 크게 부풀리지 않는다**

> ⚠️ 이전에 제가 "가슴 포켓의 원형 밸브"로 잘못 알고 있던 부분의 **영상 확증**이다.
> 실제는 **칼라에서 나온 노즐을 입에 무는 방식**이 맞다.

### 2-2. 두 개의 앵글을 교차한다

같은 동작을 **로케이션과 앵글을 바꿔 두 컷**으로 보여준다.

| | 주입 A (5.3–8.4s) | 주입 B (8.4–10.1s) |
|---|---|---|
| 앵글 | **로우앵글, 올려다봄** | **아이레벨 측면 프로필** |
| 로케이션 | 야외 골목 (붉은 벽돌) | 실내 지하철 승강장 |
| 광원 | **태양 정면 역광** — 강한 플레어 + 푸른 아나모픽 스트릭 | 승강장 형광 + 스테인리스 반사 |
| 카메라 | 핸드헬드, 더치앵글 | 안정적 고정 |
| 보이는 것 | 실루엣과 부풀어 오르는 칼라 | **노즐과 입, 손 모양** |
| 역할 | **분위기·드라마** | **동작의 정확한 설명** |

> **설계 의도**: 한 컷은 멋을 만들고, 다른 컷은 사용법을 알려준다. 둘을 나눠 찍었다.

### 2-3. 매크로 인서트 (10.1~12.9초)

- 얼굴 없이 **칼라만** 극단적 클로즈업, 얕은 심도
- 크링클 나일론 질감과 봉제선이 드러남
- 부풀어 오른 칼라의 **두께와 곡률**을 보여주는 컷
- 배경은 완전히 날아가 있음

## 3. 실루엣 변화 — 이 영상의 핵심 자산

| 시점 | 칼라 상태 |
|---|---|
| **4.6s (수축)** | 후드가 **납작하게 늘어져** 어깨선을 따라 흐른다. 목도리를 두른 듯한 낮은 실루엣. 목베개라는 인상이 전혀 없다 |
| 8.4s (주입 중) | 눈에 띄게 부풀어 오름 |
| **13.5s (완성)** | 목 둘레에 **두꺼운 원통이 곧게 서서** 턱선을 감싼다. 어깨 위로 확연히 솟음 |
| 17.0s (유지) | 측면에서 큰 라운드 매스, 드로우코드 토글이 포인트 |

> ⭐ 이 **"납작한 후드 → 곧게 선 두꺼운 튜브"** 전환이 제품의 전부다.
> `core-features.md` C-1의 **"안 쓸 땐 티도 안 납니다"** 논거가 이 영상에 이미 시각적으로 들어 있다.
> 다만 **자막이나 카피로 그것을 말하지 않는다.** 보여주기만 하고 언어화하지 않았다.

## 4. 사운드 — 숨소리를 쓰지 않는다 ⚠️

초당 RMS 측정 결과:

```
0s -40.9 → 1s -33.8 → 8s -31.8 → 17s -30.8 → 25s -30.8
```

- **완전히 평탄하다.** 주입 구간(5~10초)에 어떤 스파이크도 없다
- 즉 **음악 트랙 단독.** 부는 숨소리·바람 소리 SFX가 **전혀 없다**
- 볼륨은 24초에 걸쳐 -33dB → -31dB로 아주 완만히 상승 (자연스러운 빌드)

> **판단 포인트**: 브랜드 톤은 "조용하고 세련되게". 반면 UGC/릴스 문법에서는
> **숨소리와 팽창 소리가 강력한 후킹 장치**다. UGC 영상에서는 의도적으로 다르게 갈 여지가 있다.

## 6. UGC 영상 제작에 적용할 것

### 6-1. 그대로 가져올 것 ✅

1. **주입 동작 = 짧은 검정 노즐을 입술에 물고, 손으로 감싸 쥐기.** 호스는 드러내지 않는다
2. **같은 동작을 앵글 2개로 나눠 찍기** — 하나는 분위기(역광·실루엣), 하나는 설명(측면·손동작)
3. **매크로 인서트** — 얼굴 없이 부푼 칼라만. 질감과 두께를 보여주는 컷
4. **수축 → 팽창 실루엣 대비**를 반드시 넣기. 이게 제품의 핵심
5. **볼을 크게 부풀리지 않기.** 입술만 오므린 절제된 동작
6. 주입 시퀀스에 **러닝타임의 40% 이상**을 배분

### 6-2. UGC에서는 다르게 갈 것 ⚠️

| 항목 | 브랜드 영상 | UGC 영상 제안 |
|---|---|---|
| 사운드 | 음악 단독, SFX 없음 | **숨소리 + 원단 팽창음 살리기** — 릴스 후킹 |
| 자막 | 없음 | **"3초" 카운트 등 기능 언어화** (기내 UGC 장르는 자막 튜토리얼이 문법) |
| 톤 | 시크·무표정·패션필름 | 기내 UGC 톤 — 나른한 반응 (단, 과장 금지) |
| 화질 | 시네마틱, 아나모픽 플레어 | **스마트폰 화질·창광 단일 광원** |
| 로케이션 | 뉴욕 거리·지하철 | **기내 좌석** |
| 모델 | 한국 남성 | **20대 해외 여성** |

### 6-3. 브랜드가 비워둔 자리 ⭐

브랜드 영상은 **"납작한 후드 → 선 튜브"** 전환을 완벽하게 찍어놓고 **언어화하지 않았다.**

UGC 영상은 그 전환에 **말을 붙이는 것**만으로 차별화된다.
기내 UGC 장르는 룩이 전부라 **"안 쓸 땐 티도 안 난다"** 가 특히 세게 먹힌다.

## 7. 팩트 확정 사항 (기존 문서 갱신)

| 항목 | 확정 내용 | 근거 |
|---|---|---|
| **공기 주입 방식** | **칼라에서 나온 짧은 검정 노즐을 입술에 물고 분다** | 본 영상 8.4~10.1초 프레임 확대 |
| 손 모양 | 노즐 아래를 감싸 쥠, 엄지·검지로 파지 | 동일 |
| 표정 | 볼을 부풀리지 않음, 입술만 오므림 | 동일 |
| 수축 시 외형 | 후드가 납작하게 늘어져 목도리처럼 보임 | 4.6초 |
| 팽창 시 외형 | 목 둘레 두꺼운 원통이 곧게 섬, 어깨 위로 솟음 | 13.5초 |
| 팽창 소요 | 영상상 약 **5초 구간**에 걸쳐 묘사 (공식 카피는 "3초") | 5.3~10.1초 |

> ⚠️ 영상은 주입을 5초 가까이 보여주지만 **공식 카피 표기는 "3초"** 다.
> 자막에 숫자를 쓸 때는 **"3초"** 를 유지할 것. (`core-features.md` A-3)

## 8. 아직 확인 못 한 것

- **배기(공기 빼는) 장면 없음** — 이 영상엔 없다. "안 쓸 땐 티 안 남"을 실증하려면 별도 소재 필요
- 노즐을 칼라에서 **꺼내는 동작**이 생략돼 있다 (이미 물고 있는 상태로 컷 시작)
- 원본 캡션·해시태그 미확인 (영상 파일만 받음)
